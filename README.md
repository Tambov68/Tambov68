I develop and iterate on gameplay systems for Unreal Engine, with a focus on how movement, interaction, animation and cameras work together in play.

## Current work — SA_Rebuilt Runtime

An experimental Unreal Engine 5.8 C++ plugin and a small BMX demo, developed as part of SA_Rebuilt. The public repository contains reusable gameplay code and documented integration requirements.

- **BMX interaction:** mounting, dismounting, recovery and collision-aware exits.
- **Bicycle movement:** steering, pedals, hops and wheelies.
- **Rider integration:** procedural pose and IK targets; animation setup is still being developed.
- **Vehicles and cameras:** interaction components, ride camera and photo mode.

**Current focus:** stable obstacle contacts, bunny-hop transitions and rider animation.

[Explore the source and demo →](https://github.com/Tambov68/SA_Rebuilt_Runtime)

## How I work

Small, reviewable changes; reproducible bug reports; focused tests; and clear notes on what is implemented and what still needs validation.

**Tools:** Unreal Engine 5.8, C++, Blueprints, Chaos physics and Python for editor workflows.

## Collaboration

Bug reports, integration feedback and focused pull requests are welcome. For a useful report, include the engine version, reproduction steps, expected behaviour and relevant logs. Read the [contribution guide](https://github.com/Tambov68/SA_Rebuilt_Runtime/blob/main/CONTRIBUTING.md) before submitting changes.
